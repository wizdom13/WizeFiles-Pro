Full-featured by design

Serious capability without losing focus

WizeFiles concentrates on managing files and storage. Everyday actions stay approachable, while advanced tools are ready when a job becomes complex.

⌘

Adaptive browser workspaces

Keep several locations open with multi-tab workspaces. Switch to dual-pane on wide screens, choose the active pane, resize the divider and copy, move or drag files directly to the opposite pane.

  • Independent navigation, history, search and selection per pane
  • Tabs for local, cloud and network folders
  • Multiple Android windows remain available
☁

Cloud and network storage

Connect popular cloud providers through a guided rclone-backed flow, or add SMB, SFTP, FTP/FTPS, WebDAV and S3 locations directly.

  • Simple mode for everyday users
  • Power-user configuration when needed
  • Provider-specific icons and saved accounts
  • One browser across local and remote paths
⌁

Nearby and local sharing

Move files directly between WizeFiles devices or securely expose selected folders on your local network.

  • QR-authenticated, resumable Nearby Transfer
  • Browser access with HTTP or HTTPS
  • Optional FTP or FTPS compatibility
  • Selected roots, expiring sessions and Transfer Center history
⇄

Transfer Center

Long operations survive beyond the current screen and can recover after interruptions.

  • Running, queued, paused, completed and failed jobs
  • Pause, resume, cancel and retry
  • Speed, ETA, detailed results and destination access
  • Two concurrent long-running operations

Folder sync and backup

Create reusable sync pairs between local, removable, NAS and cloud locations.

  • One-way, mirror and two-way workflows
  • Network, charging and conflict controls
  • Previewable, persistent job history

Search and batch work

Use indexed instant search for large collections, then act on results without repetitive manual work.

  • Fast indexed search
  • Advanced batch rename with live preview
  • Numbering, replacement, prefix, suffix and patterns
  • Sorting, filtering, bookmarks and shortcuts

Storage cleanup

Understand what consumes space and stay in control of every recommendation before deleting anything.

  • Visual disk-map treemap
  • Duplicate files and duplicate media
  • Large files, old downloads, APKs, junk candidates and unused user apps
  • Review-first selection with readable reasons and safety guidance
  • Ignored-items management and a manual choice of which duplicate copy to keep

Built-in viewers, players and readers

Inspect more files without interrupting your current folder, tab or remote-storage workflow. Common formats use Android-native paths first; bounded fallbacks handle specialist content.

  • Image Viewer with sibling swiping, zoom, rotation and large-image tiling
  • Video Player plus a background-capable Audio Player with queue and headset controls
  • PDF Viewer & Reader with progressive pages, zoom, search, selection and password support
  • E-book Reader for EPUB and supported unencrypted MOBI/Kindle books
  • Offline Document Reader for HTML/XHTML, MHTML, CHM and MAFF
  • ICO/CUR, TIFF/BTF, camera RAW and TGA-family image decoding
  • Media3-first playback with LibVLC fallback for uncommon audio/video codecs
  • TTF, OTF and TTC Font Viewer with metadata, editable specimen text, multilingual samples and a 12–84 sp preview

Archives and disk images

Browse supported archives and disk images as read-only virtual folders, then preview or copy out only what you need.

  • 7z, ZIP, RAR/RAR5, CAB, WIM, XAR, ARJ, LHA/LZH and more
  • ISO/UDF, DMG, APFS, EXT, FAT, HFS+, NTFS and SquashFS
  • QCOW2, VDI, VHD/VHDX, VMDK and partition containers
  • Password, traversal, expansion and size safety limits
  • ZIP/7z/TAR.XZ editing workflows

App Manager and APK backup

Search, filter, sort and manage apps visible to the current Android profile without treating packages like ordinary files.

  • All, user, system and disabled-app filters
  • Open, inspect, enable or disable apps, with system-app safeguards
  • Android-confirmed uninstall for eligible user apps
  • Share regular and split-package backups
  • Durable .apk/.apks backup through Transfer Center—never application data
⬇

Verified Android package installer

Review and install standalone or split Android packages through one validated workflow.

  • APK, APKS, APKM and XAPK support with complete signature and package-identity verification
  • Device-compatible ABI, density and locale split selection
  • Version, signer, permission, feature and component comparison before installation
  • Android-confirmed ordinary installs, root-gated downgrades and an explicit Core Patch-compatible signature-mismatch path
  • Validated XAPK OBB placement after APK success, with rollback, partial-completion reporting and retry

AAB files can be signed and verified, but installation requires a future bundletool conversion pipeline.

✓

Android package sign, verify & import

Work with standalone APKs, app bundles and split-package containers without leaving the WizeFiles storage workflow.

  • APK v1, v2 and v3 signatures plus optional detached v4 .apk.idsig
  • AAB JAR signing and verification with PKCS#8/X.509 or PKCS#12, JKS and BKS key stores
  • APKS re-signing that preserves bundletool toc.pb bytes and verifies the complete reconstructed split set
  • XAPK re-signing that preserves manifest.json, OBB expansion files and other non-APK payloads byte-for-byte
  • Verifier-first APKM import to an open APKS container without changing the original APK bytes or signatures
  • Provider-aware Transfer Center jobs with mandatory output verification; source files are never overwritten

AAB signing is included; on-device AAB-to-APKS generation is intentionally outside the current scope.

⌫

Trash Bin and secure shred

Choose recoverable deletion for ordinary work or an explicit irreversible path for supported local files.

  • Trash Bin for recoverable local deletion
  • Provider-managed trash where supported by connected cloud storage
  • One-pass zero overwrite, sync and permanent deletion for writable local files and folders
  • Secure shred is excluded for remote, SAF, archive and mixed-provider selections

Flash wear levelling, snapshots and synchronized copies mean software overwrite cannot guarantee physical erasure.

◈

Encryption, private vaults and app protection

Protect individual files or keep a managed encrypted workspace without sending content to a remote service.

  • Standalone AES-256-GCM or ChaCha20-Poly1305 file encryption
  • Argon2id or bcrypt password derivation with explicit decrypt workflows
  • Named encrypted vaults with password and optional biometric unlock
  • Secure import, folder organization, open/edit re-encryption, locking and encrypted backup export
  • Optional password or biometric protection for the WizeFiles browser with a configurable relock interval

File details, integrity and advanced permissions

Inspect what a file really contains and, where elevated access permits, manage low-level filesystem attributes.

  • General size, location, timestamps, contents and symbolic-link details

  • Image EXIF and GPS details plus audio and video metadata
  • APK package, version, SDK, requested-permission and signing-certificate details
  • Root-capable owner, group, access-mode and SELinux-context editing, including recursive changes

Private by architecture

Control sensitive files and credentials

WizeFiles uses local-first storage controls, Android-protected credential facilities and explicit user-selected connections. Standalone file encryption, secure vaults, biometric unlock, an optional app lock and memory-only package-signing passwords protect private workflows.

Security is part of the workflow

  • Selected files can be encrypted independently with password-derived AES-256-GCM or ChaCha20-Poly1305 protection.
  • Vault content stays separate from ordinary browsing.
  • Remote accounts are added only when the user chooses them.
  • Root and Shizuku are optional, advanced access paths.
  • Nearby transfers require receiver approval and a fresh verification QR.
  • Saved web documents and e-books are staged privately with network access blocked.
  • Archives, disk images and decoders enforce path, size and expansion limits.
  • Package-signing passwords never enter durable job metadata; interrupted signing requires the key to be unlocked again.
  • APKS, XAPK and APKM operations verify the complete contained APK set before accepting the output.
  • The installer verifies package identity and signatures before selecting compatible APK splits; signing mismatch is blocked by default, with a separate warned opt-in for rooted Core Patch-compatible systems.
  • Standalone encryption and encrypted vaults keep protected content local, with explicit passwords, biometric options and recovery-aware editing.
  • Secure shred is restricted to writable local paths and is clearly separated from recoverable Trash Bin deletion.
  • Cleaner recommendations start review-first, support ignored items and preserve a user-selected duplicate copy.
  • Destructive actions use confirmations and recoverable deletion where supported.
